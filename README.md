# 🚃 Train Plugin

**Spigot 1.21.1 対応** のトロッコ連結プラグインです。  
チェーンアイテムを使って複数のトロッコを連結し、列車のように走らせることができます。

---

## 📋 概要

| 項目 | 内容 |
|------|------|
| 対応バージョン | Spigot / Paper 1.21.1 |
| 動作 Java バージョン | Java 17 以上 |
| プラグインバージョン | 1.0.0 |
| 作者 | kubota6646 |

---

## ✨ 特徴

- 🔗 **チェーンを使った直感的な連結操作** — 特別なコマンドを覚えなくてもアイテム操作だけで連結できます
- 🚂 **複数台の連結（列車編成）** — A→B→C のように何台でも数珠繋ぎにできます
- 🛡️ **循環連結の防止** — 誤って輪になるような連結はできないよう自動でブロックします
- 🎛️ **全種類のトロッコに対応** — 通常・チェスト・かまど・ホッパー・TNT トロッコすべてが連結可能です

---

## 🔧 インストール方法

1. [Releases](../../releases) から最新の `Train-1.0.0.jar` をダウンロードします
2. サーバーの `plugins/` フォルダに jar ファイルをコピーします
3. サーバーを再起動（または `/reload confirm`）します

---

## 🎮 使い方

### トロッコを連結する

1. **インベントリに「チェーン」アイテムを用意します**（クラフト or /give で入手）
2. チェーンをメインハンドに持ちます
3. **1台目のトロッコを右クリック** → 「1台目のトロッコを選択しました」と表示されます
4. **2台目のトロッコを右クリック** → 「トロッコを連結しました！」と表示されます

```
[ トロッコA ] ──チェーン──> [ トロッコB ]
   (リーダー)                  (フォロワー)
```

> **ポイント:** 最初に選んだトロッコ（リーダー）が先頭になり、2台目（フォロワー）が後ろに追従します。

---

### 3台以上を連結する（列車編成）

同じ手順を繰り返すだけで、何台でも繋げられます。

```
例: A → B → C の順に連結する場合

1. A と B を連結（A がリーダー、B がフォロワー）
2. B と C を連結（B がリーダー、C がフォロワー）

結果: A → B → C （3両編成の列車）
```

---

### トロッコの連結を解除する

#### 方法1：アイテム操作

チェーンを手に持ち、**スニーク（Shift）しながら対象のトロッコを右クリック** します。

#### 方法2：コマンド

トロッコに乗った状態で以下のコマンドを実行します。

```
/train unlink
```

---

## 💬 コマンド一覧

| コマンド | 説明 | 権限 |
|----------|------|------|
| `/train` | ヘルプメッセージを表示 | `train.use` |
| `/train link` | 連結方法の案内を表示 | `train.use` |
| `/train unlink` | 乗っているトロッコの連結を解除 | `train.use` |

> タブ補完に対応しています。`/train ` まで入力して Tab キーを押すとサブコマンドが表示されます。

---

## 🔑 権限一覧

| 権限ノード | 説明 | デフォルト |
|------------|------|-----------|
| `train.use` | トロッコの連結・解除を行う権限 | 全プレイヤー（`true`） |

---

## ⚠️ 注意事項

- 連結情報はサーバーのメモリ上にのみ保存されます。**サーバーを再起動すると連結はリセット**されます
- 1台のトロッコに連結できる前後のトロッコはそれぞれ **1台ずつ** です（枝分かれ構造は非対応）
- 循環する連結（A→B→A など）はプラグインが自動的に防止します

## 🛠️ ビルド方法（開発者向け）

Java 17 以上と Git がインストールされた環境で以下を実行します。

```bash
# リポジトリをクローン
git clone https://github.com/kubota6646/Train.git
cd Train

# Gradle でビルド（初回はラッパーが自動ダウンロードされます）
./gradlew build

# ビルド成果物の場所
# build/libs/Train-1.0.0.jar
```
